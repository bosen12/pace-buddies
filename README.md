# 跑跑夥伴 · Pace Buddies

把電腦的忙碌，交給一群可愛的小夥伴。

Windows 10 / 11 原生桌面工具；每隻角色都能使用自己的 GIF，並依 CPU、實體記憶體或 GPU 使用率自動調整動畫速度。

## 下載與開始使用

從 [最新 Release](https://github.com/bosen12/pace-buddies/releases/latest) 下載 [Windows x64 免安裝 ZIP](https://github.com/bosen12/pace-buddies/releases/download/v0.4.2/PaceBuddies-0.4.2-win-x64.zip)，解壓縮後開啟 `PaceBuddies.exe`。也可直接下載 [單一執行檔](https://github.com/bosen12/pace-buddies/releases/download/v0.4.2/PaceBuddies.exe)。

不需要安裝 .NET，也不需要管理員權限。免安裝包可以整個資料夾移動。Release 附有 `SHA256SUMS.txt` 可核對下載檔案。

![跑跑夥伴管理視窗](https://raw.githubusercontent.com/bosen12/pace-buddies/main/docs/images/manager.png)

預設有三隻原創像素夥伴：麻糬（CPU）、布丁（RAM）、啾啾（GPU）。左邊選角色，右邊修改設定，變更會自動儲存。可新增最多 20 隻，新增的角色與其他角色互不影響。

- **匯入 GIF**：按「匯入 GIF」，或把 GIF 拖進管理視窗，會替目前選取的角色換外觀。匯入後會另存一份，原始檔案移動後仍可使用。選內建角色可切換回預設外觀。
- **雙模式**：每隻可以獨立開啟「桌面懸浮」和「工作列固定（箭頭左側）」，也可以同時顯示。工作列角色是一排固定在 `˄` 隱藏圖示箭頭左側的動畫，不會被收進箭頭裡；只有靜態管理圖示仍使用系統匣。
- **速度**：最低速度對應 0% 負載、最高速度對應 100%，中間連續換算。1× 表示 GIF 原本的每格播放時間；最低與最高速度範圍為 0.1×–8×，兩者相同可固定速度。
- **變速緩衝**：0 秒立即反應，數值越大，速度變化越柔和；此數值是平滑時間常數，不是延遲多久才更新。
- **GIF 尺寸**：工作列 GIF 會用滿可用高度，寬度依原始比例向左右展開，例如可用高度 44 像素時，4:1 的 GIF 約為 176×44。桌面「角色高度」控制 GIF 畫布的高度，寬度也會跟著比例展開。原圖內的透明留白不會自動裁掉。
- **使用率數字**：每隻可選常駐、滑鼠移上去顯示、隱藏。工作列常駐數字放在 GIF 旁邊，不占動畫高度；桌面數字放在獨立的下方區域。
- **寬 GIF 與多角色**：工作列空間不足時，GIF 仍保留高度與比例，點角色列兩側的 `‹`、`›` 或使用滑鼠滾輪左右查看。不會為了塞進正方形而縮扁。桌面 GIF 寬度超過螢幕時，也可以用滾輪左右查看。
- **移動**：按住桌面角色拖曳。可鎖定位置、保持置頂、開啟滑鼠穿透；位置超出目前螢幕時會移回可見區域。
- **找回角色**：點一下箭頭左側的工作列角色，可直接開啟該角色的設定。固定的管理系統匣圖示也一直保留；可以從管理視窗關閉桌面滑鼠穿透或按「把角色移回右下角」。桌面角色雙擊也可開啟管理視窗。
- **開機啟動**：左下「啟動設定」可開關「登入 Windows 時啟動」。勾選「登入後只顯示角色」後，登入時不會彈出管理視窗，點工作列角色可開啟設定。手動開啟 EXE 仍會顯示管理視窗；免安裝資料夾移動後請手動開啟一次，更新啟動路徑。
- **結束**：視窗右上角的 × 會收起管理視窗並繼續監控。要完全停止，按「結束程式」或使用固定管理圖示的右鍵選單。

## 讀值與限制

CPU 是系統忙碌時間；可能與工作管理員經頻率效能校正的數字不同。RAM 是已使用的實體記憶體比例。GPU 是所有顯卡中最忙碌的實體引擎，包含 3D、運算、複製等引擎，並會加總同一引擎的不同程序；不是顯示記憶體比例或溫度。驅動程式未提供資料時會顯示「無法讀取」，動畫維持最低速度。

每秒取樣一次，共用最高 30 Hz 動畫時鐘；管理視窗與角色都不可見，或全部暫停時，會停止動畫計時器，仍每秒更新監控。1× 會遵循 GIF 的影格時間；GIF 中小於 20 ms 的影格以 20 ms 處理，10 秒以上的影格以 10 秒處理。高倍速時會略過來不及顯示的影格，不會增加更新頻率。

工作列模式會依主要螢幕的水平工作列、通知區位置與 DPI 自動定位；角色跟隨工作列顯示；工作列自動隱藏，或全螢幕程式實際蓋住工作列時，才會暫時隱藏，離開後會恢復。開啟程式時即使暫時出現滿螢幕內容區，只要工作列仍在前方，角色就繼續顯示。一般視窗與最大化視窗不會因外框碰到螢幕邊緣而被誤判成全螢幕。角色列會接收 Windows 視窗切換、重排與工作列位置事件立即更新，另保留每半秒檢查供工作列重啟等情況恢復。這是一個獨立透明視窗，沒有修改 Explorer 或替系統工作列預留空間。空間不夠時會使用水平捲動；連最小捲動視窗都放不下，或使用不支援的工作列配置時，會在管理視窗顯示原因，可減少工作列角色或先用桌面模式，不會蓋住既有按鈕。

新的固定工作列模式目前已在 Windows 11 原生工作列驗證。Windows 10 經典工作列或第三方修改的工作列尚未驗證，可能因無法判斷空白區域而顯示空間不足；原本的桌面模式仍可使用。

0.1 版的設定與 GIF 會沿用，原本「系統匣動畫」開關改為「工作列固定」；仍使用舊設定欄位 ShowTray 保持相容。開機啟動只寫入目前使用者的登入啟動項目，可在程式內關閉。

GIF 限制：20 MB、每格 200 萬像素、300 格、總解碼 6400 萬像素。透明背景會保留；GIF 本身沒有透明背景時，程式不會自動去背。動畫持續循環播放。顯示影格依角色高度與 DPI 縮小，保留原比例與原始 GIF；相同內容與顯示高度會共用快取。每組影格上限 64 MiB，所有活動 GIF 快取合計上限 128 MiB。超過時會顯示原因並保留原外觀，可降低高度或重新匯入。儲存的 GIF 在視窗準備好後於背景依序載入，匯入途中改選角色會取消較舊的載入。

設定在 `%LOCALAPPDATA%\PaceBuddies\settings.json`，備份為 `settings.json.bak`，匯入動畫在同資料夾的 `gifs`。無法讀取的設定會保留為 `settings.corrupt-*.json`，優先嘗試備份再使用預設值。移除角色不會刪除原始或已匯入的 GIF。工作列角色顯示狀態變更會記錄在同資料夾的 `taskbar-status.log`，用來追查自動隱藏、全螢幕或空間不足；只記錄時間與原因，不記錄其他程式的名稱或內容，超過 64 KiB 會輪替一次。

程式沒有連網功能。登入啟動使用目前使用者的登錄值 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\PaceBuddies`，不需要管理員權限。

## 開發

需求：Windows 與 .NET 8 SDK。執行環境只有 Windows；核心檢查可跨平台執行。沒有第三方 NuGet 套件。

```powershell
.\build.ps1             # 編譯與核心行為檢查
.\run.ps1               # 編譯並啟動開發版
.\build.ps1 -Publish    # 建立內含執行環境的 Windows x64 發行版；首次需要網路下載 Microsoft 執行環境
```

Windows 整合檢查：

```powershell
python scripts\make-fixture.py artifacts\smoke  # 需 Pillow，僅測試使用
src\PaceBuddies\bin\Release\net8.0-windows\PaceBuddies.exe --smoke-test artifacts\smoke
```

檢查會在指定目錄中建立獨立設定、GIF、結果 JSON 與視窗 PNG，不會動到一般使用者設定或真正的登入啟動項目。另可用 `--background-smoke-test` 檢查背景啟動。

程式結構：`src/PaceBuddies.Core` 為模型、動畫時間、速度、GPU 聚合與設定儲存；`src/PaceBuddies` 為原生 UI、動畫匯入、系統監控、系統匣與桌面視窗；`tests/PaceBuddies.Checks` 為無外部套件的行為檢查。
