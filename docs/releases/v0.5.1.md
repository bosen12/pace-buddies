# v0.5.1 · 桌面自由拖曳與桌面層綁定

新增未鎖定角色的直接拖曳、右下角等比例縮放及 Ctrl＋滾輪調整。每隻角色可獨立綁定桌面層，位於一般應用下方，執行「顯示桌面」仍會顯示；取消綁定會恢復懸浮與原本置頂偏好。

- 修正 GIF 捲動容器攔截滑鼠按下，導致角色無法拖動。
- 拖放採用事件當下的座標，放開時套用最後位置；原生游標輪詢限於角色視窗外的捕捉備援。
- 修正拖曳中關閉或重建角色視窗時的重入例外，避免連同工作列角色及管理圖示一起退出。
- 鎖定同時固定位置與大小；高度範圍 48～480，小螢幕會依工作區調整有效顯示高度。
- 保留工作列 GIF 的完整高度、寬圖水平捲動、資源使用率變速與開機啟動設定。

下載 `PaceBuddies.exe` 可直接執行，或下載 ZIP 後解壓縮。不需要另外安裝 .NET。`SHA256SUMS.txt` 可供核對檔案。

升級請先在舊版按「結束程式」，再啟動新版；右上角 × 只會收起視窗。既有設定與匯入 GIF 會沿用。管理視窗左下可確認版本為 v0.5.1。
