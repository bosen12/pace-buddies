# v0.5.2 · 修正桌面層角色消失

修正部分 Windows 11 桌面合成環境下，勾選「綁定桌面層」後角色消失的問題。舊版視窗仍能收到滑鼠命中，但 GIF 沒有被合成到實際畫面；本版改用實際顯示桌面圖示的容器承載角色，保留位於一般應用下方及直接拖曳的行為。

- 已在 Wallpaper Engine 持續運行的環境驗證，不需要停用動態桌布。
- 修正取消綁定後，未勾置頂的角色可能留在桌布後方的問題。
- 新增 GIF 實際畫面像素檢查，避免僅憑視窗可見旗標或滑鼠命中就判定顯示正常。
- 保留 v0.5.1 的拖曳、等比例縮放與拖曳中安全關閉修正。

下載 `PaceBuddies.exe` 可直接執行，或下載 ZIP 後解壓縮。不需要另外安裝 .NET。`SHA256SUMS.txt` 可核對檔案。

升級請先在舊版按「結束程式」，再啟動新版；右上角 × 只會收起視窗。既有角色、GIF、位置、綁定與開機啟動設定會沿用。管理視窗左下可確認版本為 v0.5.2。
